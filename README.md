# RRG Sector Atlas

[공개 RRG 상황판 열기](https://zqvo04.github.io/RRG/)

SPY 대비 미국 Select Sector SPDR 11개의 주간 상대강도 회전을 보여 주는 반응형 RRG-style 웹입니다. 공식 JdK 지표를 복제한다고 주장하지 않으며 공개 상대가격 기반의 `rrg_proxy_v2` 산식을 사용합니다.

정적 웹은 검증된 스냅샷만 읽습니다. 매주 수집 작업은 완료된 미국 거래 주차, 최소 이력, 중복 주차, 양수 조정종가, 심볼 수와 기준일 정렬을 확인합니다. 발행 후에는 공개 페이지와 `latest.json`의 스냅샷 ID가 일치하는지도 검증합니다. 검증에 실패하면 기존 정상 화면을 유지합니다.

## 화면에서 확인할 수 있는 정보

| 영역 | 제공 정보 |
|---|---|
| 상단 상태 | 기준일, 데이터 신선도, 검증 상태 |
| 이번 주 요약 | Leading 수, 사분면 전환 수, 100선 접근 수, 품질 게이트 결과 |
| 회전 이벤트 | 사분면 전환, 기준선 접근, 강한 이동을 중요도 순으로 표시 |
| RRG 지도 | 4·8·12·26주 실제 궤적, 자동/고정 축, 방향과 선택 섹터 상세 |
| 검증 내역 | 수집된 시리즈 수와 발행 전 품질 검사 결과 |

## 로컬 실행

```bash
python -m pip install -e ".[dev]"
pytest -q
cd web && npm install && npm run dev
```

실제 스냅샷 실행에는 `ALPHAVANTAGE_API_KEY` 환경 변수가 필요합니다. 원본 가격 응답과 API 키는 Git이나 정적 배포물에 저장하지 않습니다.
